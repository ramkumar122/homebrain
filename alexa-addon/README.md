# Alexa+ add-on package

Scaffolded with the official `alexa-ai` CLI (`alexa-ai new mcp`), which ships Amazon's Add-on Agent Skill.
The CLI is downloaded from the Alexa Developer Console after login. It is **not** the unrelated `alexa-ai` package on public npm.
We stop before `alexa-ai deploy`: deploying needs Alexa+ MCP Toolkit access, which we do not assume.
